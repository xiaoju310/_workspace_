# 01. 赛题背景与团队角色职责

## 一、竞赛与项目概况

- **赛事名称**：第二届北京市大学生“人工智能+”创新大赛
- **赛道赛题**：好未来企业赛题《“纸书智伴”：纸质图书多模态智能升级与智能伴读》
- **核心目标**：将传统的静态纸质图书（绘本、故事书、科普读物），通过多模态 AI 技术（视觉 OCR/目标检测、多智能体协作、语音识别与合成、时空索引与视频生成），升级为有声、有画、有交互响应的“智能互动伴读”体验。

## 三、角色 C 第一周（D1~D7）核心交付指标

1. **D1 免转码音频直出**：Web Audio API 录制并直出 16kHz 16-bit 单声道 PCM WAV Blob，省去服务端转码损耗。
2. **D2 触控黑边拦截与归一化换算**：消除播放器 `object-fit: contain` 黑边误触，精准输出 `[0, 1]` 归一化比例与原始像素。
3. **D3 真实普通话 ASR 接入**：基于 Web Speech API 真实普通话识别，提供静音拦截与错误码定义，严禁空转写替用户造句。
4. **D4 视频时间轴多源证据检索**：基于分镜脚本、书页 OCR、时间片与实体关键词建立倒排证据索引。
5. **D5 RAG 依据短答防幻觉引擎**：绘本问答严格受限在检索到的证据切片内，超纲未知问题 100% 诚实拒答。
6. **D6 TTS 动态声波播放器**：普通话语音朗读，支持律动声波、语速调节、首包延迟 (TTFA) 毫秒级度量。
7. **D7 会话留痕、指标看板与端到端集成**：会话全量可溯源历史、延迟监控仪表盘、笔记生命周期与 15 项自动化基准测试跑测台。
