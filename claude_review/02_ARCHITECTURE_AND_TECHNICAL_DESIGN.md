## 二、关键算法实现详解

### 1. 触控黑边拦截与坐标映射 (`VideoCoordinateMapper.ts`)

- **痛点**：视频播放器通常配置 `object-fit: contain`。当播放器长宽比与视频源不一致时，上下会产生 Letterbox（黑边），或左右产生 Pillarbox（黑边）。若直接按 DOM 坐标计算比例，点击在黑边上会导致坐标超出 `[0, 1]` 或命中错误的画面物体。
- **算法**：
  1. 获取视频原始分辨率 `origW`, `origH` 与 DOM 容器物理分辨率 `contW`, `contH`；
  2. 计算等比例缩放系数：`scale = Math.min(contW / origW, contH / origH)`；
  3. 计算实际渲染视口：`renderW = origW * scale`, `renderH = origH * scale`；
  4. 计算黑边留白偏移：`offsetX = (contW - renderW) / 2`, `offsetY = (contH - renderH) / 2`；
  5. 边界判定：若 `clickX < offsetX || clickX > offsetX + renderW`，直接判定为 `isInsideVideo = false`，毫秒级阻断并不发网络请求；
  6. 归一化换算：`normX = (clickX - offsetX) / renderW`, `normY = (clickY - offsetY) / renderH`。

### 2. 免转码 WAV 录音直出 (`AudioRecorderHelper.ts`)

- **痛点**：传统 Web 录音输出 webm/ogg，后端大模型或 ASR 服务必须经过 ffmpeg 转码成 wav 才能处理，增加 200~400ms 的网络与 CPU 开销。
- **算法**：
  1. 通过 AudioContext 捕获原生 Float32 PCM 流；
  2. 无论用户麦克风硬件是 44.1kHz 还是 48kHz，在前端使用线性插值算法无损重采样为 16000Hz；
  3. 手动构造标准 44 字节 RIFF/WAVE 文件头（写入采样率 16000、单声道 1、位深 16-bit）；
  4. 将 Float32 音频振幅钳位并换算为 16 位有符号整型写入缓冲区，直出标准 WAV Blob。

### 3. 防幻觉 RAG 证据短答引擎 (`PictureBookRagEngine.ts`)

- **痛点**：儿童绘本伴读最忌讳“AI 大模型胡说八道”，必须让 AI 的回答严格基于原书事实。
- **算法**：
  1. **实体与意图分析**：对用户提问提取核心实体词与属性词；
  2. **时空窗口检索**：在当前播放时间片的前后 12 秒内检索关联的分镜脚本与书页 OCR 片段；
  3. **超纲拒答判定**：若匹配度低于阈值（如提问外部常识、虚构角色或原书未记载事实），严格返回 `uncertain: true`，明确告知“原书本段尚未提及该信息，请结合绘本书页观察”，100% 杜绝 AI 捏造。
