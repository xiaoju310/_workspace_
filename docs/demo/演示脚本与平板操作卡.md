## 约 3 分钟的讲解路线

| 时段 | 操作 | 讲解要点 |
|---|---|---|
| 0:00–0:20 | 首页，搜索/筛选书架，点击导入 | 首页保留原阅读视觉；数据为原创演示。 |
| 0:20–0:45 | 上传页“试用原创示例”，勾选授权，确认，继续校对 | 文件限制和授权提示明确，选页不上传网络。 |
| 0:45–1:10 | 校对三页文字，确认每页；进入分类并确认类型 | 低置信需人工检查；页序和文字修改保留版本。 |
| 1:10–1:35 | 开始生成，体验一次失败，重试，内容复核 | 展示的是模拟状态机和失败恢复，未调用真实视频模型。 |
| 1:35–2:00 | 进入互动阅读，试用转写、修改问题、提交；点击认物 | 画面为静态原型，回答保留来源，真实语音待 C 接入。 |
| 2:00–2:15 | 查看历史，筛选并导出 | 模拟/真实标记和 run_id 保留，延迟不作实测结论。 |
| 2:15–2:45 | 笔记提交审核，主人确认，创建限时分享，打开预览 | 笔记默认私密；只有审核当前版本后才允许模拟分享。 |
| 2:45–3:00 | 撤销分享，查看只读拒绝页 | 修改笔记会使旧审核和分享失效；真实访问权限由 A 实现。 |

`frontend-simulation.webm` 是实际浏览器操作录屏，无音轨。画面顶部持续标注“前端模拟流程录屏 · 非真实模型生成 · 无音频”。它供本地 UI 评审和故障备用，不能代替赛题真实视频或正式现场演示。

## 平板操作卡

1. 建议横屏，在 Edge/Chrome 通过本地 Vite 服务或双击离线 HTML 打开。
2. 左侧导航切换页面；窄屏顶部导航可横向滑动。
3. 页脚“演示状态”可切换加载、空数据、失败，回到“正常/成功”恢复。
4. 上传选择或拖放 JPG/PNG；单张 ≤10 MB，最多 24 页。真实图片刷新后需重导入。
5. 校对页先保存未完成编辑，再切换书页。页序变化需重新逐页确认。
6. 阅读页点击“点击认物”后再点实际画面；左右留白会拒绝。文本输入可替代模拟转写。
7. 笔记先保存，再提交主人审核；修改后重新审核。分享只在本浏览器会话可预览。
8. 如出现故障，保留错误和 run_id，使用 `docs/screenshots/full-*.png` 说明当前页面；明确它们是历史模拟截图。
9. “接口与演示设置”可重置本地演示，重置前先导出需要的历史记录。
