## 验收清单

- [ ] 服务健康检查可运行并记录运行 ID
- [ ] 合法绘本样本可导入
- [ ] 错误文件被拒绝并有清晰错误信息
- [ ] 页面解析结果可核对页数和顺序
- [ ] 分类、脚本、视频任务状态可查看
- [ ] 生成视频可播放
- [ ] 语音问答可返回识别结果和页面/时间证据
- [ ] 无依据问题有明确拒答
- [ ] 点击目标返回目标和坐标
- [ ] 断网/超时有可恢复错误状态
- [ ] 多书之间数据隔离
- [ ] 笔记默认私密
- [ ] 分享须经主人审核
- [ ] 分享撤销后旧链接失效
- [ ] 输出不泄露大段原文
- [ ] 日志不含密钥或儿童隐私
- [ ] 结果带版本和运行 ID，可重跑
