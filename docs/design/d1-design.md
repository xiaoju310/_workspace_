版本：v0.1 原型草案 · 2026-11-04（北京时间） · 负责人：D

## 1. 本次范围与查看方式

D1 主任务是高保真首页、上传页原型和组件清单。本次设计以可运行的 React 原型为交互参考，配套 SVG 画面供导入 Figma 后继续编辑。SVG 交付不等同于已经创建 Figma 云端文件、Auto Layout 或可发布的 Figma Prototype。

原型仅使用本地假数据和原创示意素材。页面选择文件只用于本地预览；界面必须明确“原型演示”，不得把模拟分类、模拟成功或示意封面当作真实模型结果。

运行方式见 `frontend/README.md`；双击 `docs/prototype/paper-companion-d1.html` 可离线查看。首页与上传页的路由、状态切换入口及截图文件名应在自测记录中注明。本文是设计交接，不代替实际测试结果。

## 2. 固定流程

```mermaid
flowchart LR
  H[首页：阅读工作台] --> I[导入：书名、授权信息、页图]
  I --> P[页序预览与本地校验]
  P --> C[分类确认：预测类型、置信提示、主人确认]
  C --> R[页序与 OCR 校对]
  R --> G[解析与生成进度]
  G --> V[互动播放]
  G --> N[笔记草稿]
  N --> O[主人审核]
  O --> S[分享设置与只读查看]
```

首页、上传页属于 D1 高保真画面。分类确认在本次仅预留必要字段和交接规则；OCR 校对、生成、播放、笔记审核和分享由后续每日任务实现。未实现的目的地显示“后续阶段”说明或禁用态，不跳转到伪完成页面。

首页的主要行动为“导入一本书”，书卡可查看详情；上传页提供“试用原创示例”。从上传页能够返回首页；本地选页和表单保存在页面内存中，离开上传页或刷新即清空。上传页下一步先进行表单校验；D1 原型只反馈本地结果和下一阶段说明，不发送网络上传请求。

## 3. 首页画面

信息层级：应用导航 → 阅读工作台标题 → 导入引导 → 书架 → 最近笔记。

| 区域 | 内容 | 行为 |
|---|---|---|
| 应用导航 | 品牌、首页/书架语义、导入入口、原型标识 | 当前入口有明确选中态；导航使用可聚焦链接或按钮 |
| 顶部标题 | “今天，翻开哪个世界？” | 简短说明从纸书到互动伴读的目标，不承诺已支持所有图书 |
| 导入引导 | 主行动“导入新书”、原创阅读插画 | 主行动进入上传页 |
| 最近书籍 | 示意封面、书名、图书类型、处理状态、最近笔记 | 用文字说明状态；示例图书明确为模拟数据 |
| 最近笔记 | 私密笔记、草稿、来源引用数量 | 点击可查看模拟摘要和引用 |

书籍的处理状态与笔记的可见性独立展示。例如一本书可处于 `REVIEW_REQUIRED`，其笔记仍为“草稿 · 私密”。“草稿”“私密”“已分享”不得挤进同一个互斥状态字段。

## 4. 上传页画面

主列承载输入，右侧摘要列说明本次导入及下一步。原型将授权标识和授权确认放在显眼位置，避免只在页脚提供版权说明。

| 顺序 | 字段/内容 | 验证与提示 |
|---|---|---|
| 1 | 书名 | 去除首尾空白后不能为空；保留用户输入 |
| 2 | 授权样本标识或来源说明 | 必填；不能把一项勾选视为后端权限认证 |
| 3 | 页图选择区 | 支持选择或拖入 JPG/PNG；可多选；格式和大小失败具体到文件 |
| 4 | 页图预览 | 展示序号、缩略图、文件名和本地校验结果；完整页序/OCR 校对属于 D3 |
| 5 | 类型意向 | 可预选绘本/文学/知识/其他等候选；明确“待识别/待确认” |
| 6 | 授权确认 | 用户确认拥有本次处理所需授权；说明素材不会因选择文件而自动公开 |
| 7 | 本次摘要 | 文件数、书名、类型提示、笔记默认私密、下一步说明 |
| 8 | 主行动 | 未满足必填项时给出可理解的校验提示；满足后只显示本地原型结果 |

原型中的文件大小/数量限制是演示配置，真实限制须由 A 的上传策略提供并由后端再次校验。文件扩展名和浏览器 MIME 均不足以证明文件真实有效；真实接入后由服务端解码和内容校验。

## 5. 视觉与布局约定

采用暖白背景、森林绿主色、柔和橙色点缀，强调安静阅读与可操作性。标题、正文、说明文字使用统一层级。原创 SVG 封面和插画应随源码留存，避免引用版权不明的绘本页或外部图片。

| 规则 | 桌面：1366px | 平板：1024px |
|---|---|---|
| 导航 | 固定宽度侧栏或紧凑顶栏 | 缩窄导航，保留文字含义 |
| 内容容器 | 留白充分，首页书籍区域可多列 | 减少列数，不压缩文字至难读 |
| 上传页 | 输入主列 + 摘要侧列 | 视可用宽度缩窄侧列或将摘要移到主列下方 |
| 按钮 | 主次行动清楚 | 可触控区域建议至少 44×44 CSS px |
| 错误提示 | 紧邻字段，含补救方式 | 可见且不被固定页脚或浮层遮挡 |
| 页面边界 | 无无意义横向滚动 | 1024px 下关键控件完整可达 |

较窄手机视口应自然收为单列，但 D1 必测设备宽度为 1366px 和 1024px。正文使用系统中文字体栈，无远程字体依赖。状态不能只靠颜色区分；按钮保留键盘焦点，输入框有可访问名称，异步反馈使用适当的 `status` 或 `alert` 语义。

## 6. 组件清单

以下是职责清单；组件拆分应以最终代码结构为准，交接时同步实际名称。

| 组件 | 输入 | 输出/交互 | 状态与复用 |
|---|---|---|---|
| `AppShell` | 当前页面、子内容 | 导航、主内容、原型标识 | 首页和上传页共用；移动端可收拢导航 |
| `Button` | 变体、禁用、忙碌、点击回调 | 原生按钮行为 | 主/次/轻量；忙碌时防重复触发 |
| `Badge` | 文案、语义色 | 类型、处理状态、可见性标签 | 标签必须有文字，不把颜色作为唯一信息 |
| `BookCover` | `Book` 对象 | 原创书封示意 | 装饰图使用空替代文本，书名由正文提供 |
| `BookCard` | 书籍、类型、状态、点击回调 | 展示最近书籍和允许的操作 | 区分模拟数据与真实产物 |
| `StatePanel` | `kind`、`scope`、重试和导入回调 | 加载/空/失败反馈；成功由页面展示 | 页面共用；错误提供重试或返回 |
| 上传选择区（`ImportBookPage` 内） | 格式提示、限制、选择回调 | 多文件选择与拖放 | 空/拖入/本地读取/失败；键盘可操作 |
| 授权与导入反馈（`ImportBookPage` 内） | 书名、页数、类型、下一步 | 本次导入摘要 | 提交成功后显示书名/页数；默认私密说明 |
| 步骤条（`ImportBookPage` 内） | 步骤、当前步骤 | 导入流程位置 | 当前/后续/完成视觉不同；D1 不伪造后续完成 |
| 页图预览项 | 文件、页序、读取状态 | 缩略图、文件名、错误与移除 | 本地对象 URL 应在移除/卸载后释放 |
| 表单字段 | 标签、提示、错误、输入值 | 文字/选择/勾选输入 | 输入关联 `label`；必填和校验错误提供文字；统一错误区使用 `role=alert` |

## 7. 四种页面状态

| 页面 | 加载 | 空数据 | 成功 | 失败 |
|---|---|---|---|---|
| 首页 | 骨架或加载提示；避免内容跳动 | 无书籍说明 + “导入第一本书” | 示意书籍卡片、类型、处理状态 | 明确加载失败 + 可重试；原型使用模拟故障入口 |
| 上传页 | 本地图片读取/模拟提交提示 | 文件区为空；表单可填写 | 本地校验通过，提示原型未联网及下一阶段 | 不支持格式、过大/损坏文件、缺少书名或授权；保留已输入信息 |

成功文案应说明实际发生的事，例如“本地校验通过”，不能显示“已上传”“AI 已分析”或“视频已生成”。真实后端接入后再依据 API 响应展示结果。

## 8. 通用阅读扩展的原型约定

- 图书类型：区分预测结果与主人确认结果。未知类型保持“待确认”。
- 分类置信度：显示来源于后端的数值或“暂未提供”；低置信结果有文字提示，不能仅变更颜色。
- 主人确认：可接受预测类型或修改类型，保留确认版本；真实权限和冲突校验由 A 处理。
- 笔记：结构化摘要、人物/概念、来源页码或时间引用；默认私密。
- 审核与分享：审核通过后才允许创建分享；权限由后端判定，前端只呈现状态。未审核时分享入口说明原因。
- 以上为 D1–D2 字段草案；D1 不代表分类、笔记或分享服务已实现。
