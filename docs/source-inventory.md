## 2026-11-16 新增电脑版功能来源与待核对项

- 新增工作流、分镜编辑/审核、服务器模型适配、合成封装和测试为本项目代码；未嵌入新的开源生成模型权重。
- 图文、问答、认物调用服务器配置的豆包视觉模型；图生视频继续复用已有豆包适配。实际模型 ID 由队伍填写并在最终交付清单核对，不把作图/视频模型误记为视觉模型。本轮未发起收费调用，未确认实际视觉模型权限或效果。
- 新合成流程使用本机已有 FFmpeg；仓库不包含其可执行文件。干净环境应由使用者安装并通过 `FFMPEG_PATH` 指定；如计划随安装包分发二进制，必须先核对该具体构建及编解码器的许可和告知义务，不视为已经完成授权审查。
- 本轮真实媒体测试只生成红色/绿色纯色片段；后台浏览器回归另读取既有本机测试 MP4，不新增第三方图书原图。
- 本轮没有创建/替换猫头鹰素材，也没有验证历史素材授权。RapidOCR/ONNX 依赖版本、历史美术素材、正式演示图书和云服务使用范围仍需队伍按实际交付逐项补全，不能用本补充替代完整授权清单。
- 密钥、账号数据库、上传书页、生成视频、测试缓存和本地备份不属于公开源代码材料。
