## 3. 前后端核心接口数据契约（请 A 同学重点对齐）

### 接口 1：语音 / 文本伴读问答 (`POST /api/v1/interaction/qa`)
- **请求格式**：`multipart/form-data`
  - `audio` (File, 可选): 16kHz 16-bit 单声道 WAV 文件（若纯文本自测则为空）
  - `book_id` (string): 绘本 ID（如 `book-auth-sample-01`）
  - `run_id` (string): 生成批次 ID（如 `run-20261104-001`）
  - `video_ms` (number): 提问发生时视频播放毫秒数（整数，如 `3500`）
  - `query_text` (string, 可选): 纠错或纯文本测试提问
  - `stream` (boolean): `false`（首版采用稳定 HTTP JSON 闭环）
- **响应格式** (`application/json`)：
  ```json
  {
    "run_id": "run-20261104-001",
    "question": "这只小狐狸为什么要找妈妈？",
    "answer": "小狐狸采摘野果迷路了，正在寻找回家的路。",
    "status": "success", // 'success' | 'no_evidence' | 'error'
    "confidence": 0.94,
    "evidence": [
      {
        "page_no": 1,
        "video_start_ms": 2000,
        "video_end_ms": 5000,
        "evidence_type": "page",
        "confidence": 0.95,
        "snippet": "小狐狸背着小书包，在茂密的树林中四处张望。"
      }
    ],
    "audio_url": "/data/cache/tts_answer_001.mp3",
    "latency": {
      "asr_ms": 140,
      "retrieval_ms": 65,
      "llm_total_ms": 320,
      "tts_total_ms": 420,
      "total_roundtrip_ms": 520
    },
    "cache_hit": false
  }
  ```
  > **⚠️ 负样本防幻觉规范**：若无匹配依据（如问外星人），必须返回 `status: "no_evidence"`，答案为明确拒答，严禁硬猜。

### 接口 2：视频触控万物识别 (`POST /api/v1/interaction/touch`)
- **请求格式**：`application/json`
  ```json
  {
    "book_id": "book-auth-sample-01",
    "run_id": "run-20261104-001",
    "video_ms": 3500,
    "touch_point": {
      "norm_x": 0.3542,
      "norm_y": 0.4180,
      "video_pixel_x": 453,
      "video_pixel_y": 301,
      "video_width": 1280,
      "video_height": 720
    },
    "viewport_info": {
      "container_width": 800,
      "container_height": 450,
      "render_width": 800,
      "render_height": 450,
      "offset_x": 0,
      "offset_y": 0,
      "is_letterbox": false
    }
  }
  ```
- **响应格式** (`application/json`)：
  ```json
  {
    "run_id": "run-20261104-001",
    "video_ms": 3500,
    "status": "success",
    "target_name": "小狐狸皮皮",
    "explanation": "故事的主人公小狐狸，正戴着红色围巾寻找妈妈。",
    "confidence": 0.93,
    "bounding_box": [0.25, 0.30, 0.45, 0.55], // [x_min, y_min, x_max, y_max] 归一化
    "evidence": {
      "page_no": 1,
      "video_start_ms": 2500,
      "video_end_ms": 4500,
      "evidence_type": "video_frame",
      "confidence": 0.93,
      "snippet": "第 1 页视频第 3.5s 关键角色检测"
    },
    "latency_ms": 230,
    "cache_hit": false
  }
  ```
