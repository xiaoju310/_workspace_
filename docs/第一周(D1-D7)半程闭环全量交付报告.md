## 2. 核心架构与代码模块总览

```text
frontend/src/
├── types/interaction.ts                        # 统一交互契约（问答、触控、证据、历史、指标）
├── lib/api.ts                                  # 综合 API 客户端（双模架构：Live 后端 + 本地 RAG 引擎）
└── features/interaction/
    ├── asr/
    │   └── AsrProvider.ts                      # ASR 适配器矩阵（Backend / WebSpeech / Mock）
    ├── indexing/
    │   └── TimeSliceIndexer.ts                 # 视频时间轴映射与页码/分镜证据检索器
    ├── qa/
    │   └── PictureBookRagEngine.ts             # 依据短答生成流水线与合规防幻觉拒答
    ├── tts/
    │   ├── TtsProvider.ts                      # TTS 语音合成驱动（支持首音频耗时测量）
    │   └── TtsPlayerWidget.tsx                 # 语音播报组件（声波微动效、语速调节）
    ├── history/
    │   └── InteractionHistoryPanel.tsx         # 多模态会话历史面板（支持 JSON 导出与证据跳转）
    ├── metrics/
    │   └── LatencyMetricsDashboard.tsx         # 交互延迟指标仪表盘（平均值、阶段分解与达标指示）
    ├── AudioRecorder.tsx & AudioRecorderHelper.ts # 录音组件与免转码 16kHz WAV 编码
    ├── VideoCoordinateMapper.ts & TouchOverlay.tsx# 触控坐标映射与黑边 (Letterbox/Pillarbox) 拦截
    ├── BenchmarkRunner.tsx                     # 自动化基准评测台（15 个核心用例一键跑测）
    ├── ReadingNotesDrawer.tsx                  # 通用阅读扩展（分类确认与笔记审核）
    └── __tests__/
        ├── VideoCoordinateMapper.test.ts       # 坐标与黑边单元测试 (3 tests)
        ├── TimeSliceIndexer.test.ts            # 时间片索引单元测试 (4 tests)
        └── PictureBookRagEngine.test.ts        # RAG 与拒答单元测试 (3 tests)
```
