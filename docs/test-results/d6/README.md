## ASR/检索/回答分类

ASR：对真实录音逐字比标准文本，标错字/漏字/插字/无语音/权限/网络/超时。本次未识别音频，ASR错误不可判定。
检索：使用人工确认的正确转写，检查页码与证据是否能回答该问题；保留漏召回、无关证据和不支持的原因推断。
回答：检索正确但仍误答、添加无依据事实或未拒答，独立记错；错误可同时影响多个阶段。
