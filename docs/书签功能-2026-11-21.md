# 开卷有灵：书签功能（2026-11-21）

## 使用方式

1. 在电脑版打开图书的互动伴读页，标题下方显示“本书书签”。
2. 点击“添加书签”，可选填最多500字的备注，再点“保存书签”。
3. 展开书签列表，点击“回到书页”打开原书页；可修改备注或确认删除。
4. 查看书签后，可点“返回刚才位置”继续之前的阅读。

## 行为与保护

- 每本书独立保存多个书签，同一书页只保留一个；重复添加本页会进入备注编辑。
- 书签按稳定书页ID关联，不按数组下标记页；书页重排不会跳错，原书页移除后禁止跳转。
- 静态书页自动选择当前页；视频仅在时间轴准确时自动选择当前页，否则要求手动选择。
- 视频有可靠时间轴且可播放时，跳转会暂停并定位到该页；否则只打开原书页，不伪造视频时间。
- 书签独立于自动续读记录，添加、编辑、删除不会覆盖续读位置；实际跳页仍按原有逻辑记录阅读进度。
- 沿用现有本机草稿保存、账号隔离与账号草稿同步机制；旧草稿无书签字段也可正常使用。
- 保存/同步失败仍由工作台现有提示告知，不将界面更新文案冒充云端保存成功。
- 本次仅增加电脑版与其离线预览的书签入口；手机/平板独立界面未新增入口。
