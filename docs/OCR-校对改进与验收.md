# 自动 OCR：校对改进与验收

更新：2026-11-16。电脑端与独立手机／平板端同步。

## 已修改

1. 把校对页“识别置信度 xx%”改为“识别参考分 xx / 100”。不再使用绿色高分暗示识别正确；明确参考分不是准确率，也不评价人工修改后的文字。
2. 所有书页都提示核对正文、阅读顺序、引号与标点，而非仅提醒低于 80 分的页面。低分仍有额外提醒；无效或缺失分数显示“暂未提供”。
3. 对少量可疑独立行按行号提醒，例如 `●`、`à`、`II`。不自动删字，不统一过滤短行、页码、英文或标点。提醒可能误报，未提示也不代表无错字。
4. 重新识别时显示本次返回的参考分，保存时随草稿保存，避免旧分数配新结果。未保存的修改与已确认页仍受保护。
5. 页面补充铺平书页、正对拍摄、避免反光、保留完整正文的提示。未增加自动重写原文、自动删字或默认图片增强功能。
6. 保留人工校对和确认流程；不自动保存、自动确认 OCR 草稿，不自动跳过分类前的逐页确认。

## 本机测试（已经运行）

素材：本项目原创《龟兔赛跑》6 页，每种条件测试全部 6 页，共 **30 次真实调用本机 OCR**。各类条件均为电脑合成变换，**不是纸书实拍**。

| 条件 | 变换方式 | 主要观察 |
| --- | --- | --- |
| 清晰原图 | 不改变素材 | 六页正文汉字基本完整，仍有引号缺失和装饰误识别 |
| 模拟倾斜 | 旋转 5 度，扩展画布避免裁掉正文 | 第 2、4 页有正文阅读顺序错乱／重复；第 2 页参考分约 93 / 100，仍不能代表识别正确 |
| 模拟反光 | 正文区域局部半透明白色覆盖 | 这组图片正文汉字基本保留，仍有杂字符和标点问题；不能推断严重反光也能识别 |
| 模拟小字模糊 | 尺寸缩到 35%，高斯模糊 0.6 | 这组图片正文汉字基本保留，仍有句末引号缺失；不代表密集小字号书页已验收 |
| 模拟弯曲 | 逐列纵向位移，最大 24 像素 | 这组图片正文汉字基本保留，仍有换行、标点和杂字符问题；未模拟严重透视变形 |

30 次识别共约 63.8 秒，单页约 1.3–3.0 秒。速度仅代表本次本机运行，包含首张模型初始化和运行负载，不是性能承诺。

“正文汉字基本保留”仅指人工对照本次短篇样本，不能等同于标点、段落顺序、页脚均正确，也不是通用准确率评测。没有使用模型参考分计算准确率。

### 如何复测

在仓库根目录执行：

```powershell
backend\.venv\Scripts\python.exe scripts\evaluate-ocr.py
```

需要预先安装 `backend/requirements-ocr.txt`。脚本不连接账号或数据库，不改动正式图书；输出位于仓库 `test-results/ocr-evaluation/`：

- `report.md`：每页对照正文、识别全文、参考分和耗时。
- `results.json`：结构化结果。
- `baseline-01.png` 等：可供查看的测试图片。

`test-results/` 已被忽略，不作为正式图书提交；上述路径为相对仓库的位置。

## 仍须进行的真实拍照验收

目前没有真实拍照素材，不能标记以下项目为通过。建议用有权使用的书籍，每类拍 3–5 页：

- 正常光线、书页铺平、镜头正对。
- 轻微与明显反光，分别记录遮挡文字的位置。
- 倾斜／透视、弯曲书脊、小字密集正文。
- 正文覆盖插画、多栏、竖排、手写文字（各自单独记录，不混算成绩）。

每张保留原图并人工录入对照文字，分别检查错字、漏字、引号与标点、阅读顺序、杂字符；高分错误也要记录。若真实拍照确有明显问题，再针对性添加可选裁剪／纠偏／增强，保留原图并对比改前改后，不盲目默认处理所有图片。
