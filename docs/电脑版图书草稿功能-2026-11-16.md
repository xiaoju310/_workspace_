# 电脑版：图书草稿功能（2026-11-16）

## 已实现

- **导入自动草稿**：书名、类型、授权来源、授权勾选、原图、页序都会保存。也可点击“保存草稿”。
- **继续/删除**：首页上方“我的导入草稿”可继续编辑或删除；删除前需确认。支持多本未完成草稿。
- **刷新继续**：编辑草稿时地址包含草稿标识，刷新可继续；浏览器关闭后重开，可从首页进入。
- **书架持久恢复**：转入校对后的书、原图、版本、确认状态、笔记和阅读记录保存在本机。已经导入的书从书架继续。
- **未确认文字也保留**：校对框尚未点击“保存校对”的输入作为单独草稿保存；不会冒充已审核原文或自动加入问答证据。放弃修改会清除此页输入草稿。
- **保存提示**：显示正在保存/已保存/失败；未保存完成时关闭页面会尽力触发浏览器提醒。请等到“已保存”后再关闭。
- **账号和模式隔离**：按当前用户 ID 与真实/演示模式区分。此为应用层隔离，不是同一电脑上的加密保险箱。

## 实现与边界

1. IndexedDB 保存图片 Blob，避免 localStorage 的容量限制和 blob 链接刷新失效。重复文字编辑不会重复写入整本原图。
2. 顺序写入，失败不显示成功；转入书架和删除导入草稿在同一个事务中完成。存储失败时保留原草稿，并可重试。
3. 先恢复再自动保存；读取失败时暂停自动覆盖，避免空书架覆盖旧数据。
4. 不调用生成模型或上传图片，不新增后端接口，不改手机版。后端既有建档/OCR操作仍按用户手动导入执行。
5. **仅此浏览器、此网站地址的本机草稿**，没有实现 MongoDB 云端同步。更换浏览器、电脑、地址或端口不会自动看到这些草稿。清除网站数据、使用无痕模式、浏览器回收空间可能导致丢失；重要原图仍应另存。暂不支持多个标签页同时编辑同一份书架的冲突合并。
6. 旧版已关闭页面而丢失的原图不能凭空找回，需重新导入一次；仍在旧页面内存的书页刷新前请先保留原文件。
7. 视频缓存不写入本机草稿；真实视频按服务端运行记录重新加载。重置本机书架不删除服务端对象，也不删除独立导入草稿。

## 手动验收

1. 更新后先按 Ctrl+F5；导入一本有使用权的书，只填书名/选两页图片，不继续校对。
2. 等“本机草稿已保存”，返回首页；从“我的导入草稿”点“继续草稿”，检查原图、书名、页序。
3. 关闭并重开浏览器，登录同一账号（或继续相同演示模式），重复检查。
4. 完成导入，校对框输入文字但不点保存；等书架状态“已保存”后刷新，输入应仍存在。
5. 点击“保存校对”和“确认此页”，关闭重开后从书架继续查看。
6. 删除一份不需要的导入草稿；不应影响已在书架的书，也不会删除后端数据。
