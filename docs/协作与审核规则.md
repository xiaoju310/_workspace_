# GitHub PR 协作约定

1. 每个人只向自己的 `team/*` 分支推送。提交前从 `main` 获取更新。
2. 完成一个可检查功能后发起 PR，目标分支为 `main`；PR 描述包含改动、运行命令、测试结果、风险和对应任务。
3. 由仓库负责人 xiaoju310 审核。未经其明确同意，不合并、不直接推送 `main`。
4. 测试和文档也走 PR。模型/第三方依赖需登记来源、版本和许可证；不能提交赛事受限素材和密钥。
5. 如需 GitHub **强制**阻止绕过审核，应在仓库设置里启用适用于私有仓库的分支保护/规则集，并验证普通成员无法直接推送或自行合并。仅有本文件不提供技术保障。
