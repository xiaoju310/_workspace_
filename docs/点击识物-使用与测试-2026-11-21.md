# 开卷有灵：点击识物更新（2026-11-21）

## 如何使用
1. 打开一本书，进入“互动阅读”。
2. 点击播放控制条的“点击识物”。鼠标与手机轻触均使用画面点击事件。
3. 真实识别需要后端视觉模型已配置；阅读页可手动勾选“本次开启云端问答与识物”。此操作会将书页/当前截图发送给豆包，可能按次收费；不自动授权。
4. 点击原书页或视频中的物体。系统暂停播放并用圆圈标出点击位置，在画面下方显示名称和解释；右侧可查看依据、朗读结果。
5. 识别失败可重试原位置；也可以重新点击物体。识别结束后手动点击播放继续。
6. “退出识物”仅关闭选点模式，不会自动恢复播放；若要撤销本次云端授权，请取消勾选授权复选框。

## 本次补充和修复
- 阅读页直接提供识物说明、授权、加载、结果和错误提示，不再必须到故事工坊寻找授权入口。
- 静态书页自动播放也会暂停，不再只暂停视频；视频读取实际 currentTime 锁定点击帧。
- 加入点击位置圆圈，过滤画面黑边、占位图、未就绪媒体，防止误识别。
- 截图期间同步防重复点击，同时阻止重叠提问；截图异常可恢复。
- 翻页、跳转、换书、切换运行任务或离开时，迟到的截图不再触发识别，迟到结果不再覆盖新页面。已经发送的请求无法取消已产生的模型费用；服务端记录保留供审计。
- 重试保留原坐标、原截图、页码和视频时间，不偷换为当前页；重试仍可能收费。
- 阅读页与故事工坊授权开关同步；刷新或切换登录信息清除内存授权。
- 识物不再通过旧的外部模型地址绕过授权；改为明确授权后使用本人后端接口。
- 修正静态页识物依据的类型和演示页码来源；识物卡片不再误标“仅基于校对文字”。
- 专注阅读中开启识物后，画面下方仍显示结果；不会依赖已隐藏的助手侧栏。
