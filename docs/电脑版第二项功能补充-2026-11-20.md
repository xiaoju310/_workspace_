# 电脑版：第二项功能补充（未发布）

日期按测试电脑北京时间 2026-11-20 记录，对应洛杉矶 2026-11-19。没有调用收费模型、修改密钥、下载大型模型或改动手机工程。

## 1. 全书相关内容检索

- 云端问答不再固定取当前页加前 12 页。先在全书 OCR 文字及已有图文理解中进行中文双字/英文词相关度检索，再选择最多 12 页。
- 支持“第48页”一类明确页码；尽量保留当前页作为上下文。
- 单页内容过长时选取相关段落，而不是固定截取开头。
- 响应及交互留痕包含检索方式、全书页数、选中的页码和实际检索耗时。
- 保留证据校验与拒答机制。检索不是全书穷尽总结；跨语言、同义改写、图中但未分析的内容仍可能漏检。

## 2. 可选视频配音

- 故事工坊第 3 步增加本机中文配音选择，默认关闭。
- 朗读主人已确认的分镜故事内容，不调用收费语音服务，不混入云端片段原音轨。
- 先完成全部本机配音，再提交收费视频片段；本机失败不会新增视频费用。
- 配音超出视频长度时延长末帧，音频较短时补静音；时间轴按实际视频解码时长生成。
- 初次选择及声音名称写入任务快照，恢复沿用原选择，不重发已经提交的视频片段。
- 配音中间文件正常退出或失败时清理。强制结束进程的遗留文件需要后续清理，不宣称崩溃情况下绝不留存。

## 3. 本机语音识别兜底

- 阅读页增加单独同意框。浏览器没有有效定稿、识别出错时，才发送录音给当前登录服务器的 Windows 中文语音组件。
- 独立于云端问答授权；演示模式不调用。转写后仍要求主人检查文字再提交。
- 接口需要登录、明确同意、受支持的真实音频文件头；限制 4 MB、0.1–20 秒，解码和识别有超时与并发保护。
- 录音在临时目录处理后删除，不写数据库、不调用云端；交互记录真实转写来源与上传处理状态。用户主动下载的浏览器录音不受此清理影响。
- 识别无结果/失败不编造文字；离开页面会取消浏览器等待。服务端已开始的短任务仍可能继续到结束或超时，然后清理。

### 当前环境限制（尚未完成实机验收）

同一台电脑的独立 `C:\Python314\python.exe` 能真实完成“中文配音 → WAV → 中文识别”，测试句为“小乌龟在森林里慢慢走。”，识别为“小乌龟在森林里慢慢走”，音频约 3.108 秒。

但是项目 `backend/.venv/Scripts/python.exe` 启动的 Windows 语音子进程不能初始化语音引擎。具体原因尚未确认，不自动修改系统权限、不绕过操作系统安全设置。能力检测会实际试合成及识别静音，不仅检查“已安装”；当前环境如实返回不可用，界面禁用配音/兜底，仍可用浏览器识别、键盘和无配音视频。

因此，功能代码和隔离测试已补齐，但这两项在当前一键启动环境中的真实可用性仍待修复。不要把独立 Python 验证说成当前软件端到端通过。

## 4. 视频认物证据

- 有视频资源标识时，从当前账号拥有的服务器视频按点击时间抽取真实帧，不用浏览器截图冒充真实视频。
- 模型调用前核验资源归属、文件位置、SHA256、点击时间范围及书页来源；不一致时拒绝，不提交模型。
- 兼容旧版未提供视频标识的截图请求，但始终标记 browser_snapshot_unverified，不声称核验通过。
- 成功/不确定的模型响应均登记证据图像、指纹、原视频指纹、时间、书页、点击坐标与识别结果。当前账号可以下载，其他账号不能读取。
- 工坊可下载认物证据画面，流程 JSON 可导出对应来源。浏览器本地截图与服务器证据是两份不同对象，不混淆指纹。
- 这验证的是来源和留存，不证明真实收费视觉模型的识别准确率。

## 5. 视觉模型配置

- 工坊区分“配置存在”和“权限/效果已验证”。未配置时明确说明视频模型不能替代视觉理解模型。
- 沿用 `scripts/configure-vision-model.ps1` 安全保存真实视觉模型 ID 的方式；不增加浏览器密钥输入，不猜模型编号。
- 仍需要主人提供方舟账号实际已开通的视觉模型 ID 或推理接入点 ID。没有该编号，不调用真实看图或云端问答。
