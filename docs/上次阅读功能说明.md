# 上次阅读 / 继续阅读

## 已增加

- 首页显示最近阅读的可读图书、上次页码，提供「继续阅读」与「从头阅读」。
- 每本已阅读图书的书卡显示继续阅读页码；打开书卡同样恢复进度。
- 静态书页恢复到上次页码；视频等真实时长就绪后恢复播放位置，保持暂停，不自动出声。
- 视频换运行或换产物后不直接套用旧秒数，优先按原页码和当前时间轴恢复；无时间轴时仅估算。
- 时间轴晚到时可修正尚未开始操作的页码恢复；已经播放或手动跳转后不再强行回跳。
- 历史记录指定时间跳转优先于续读；静态页导航不套用视频时间轴。
- 播放期间约每5秒、跨页、暂停、切出页面、离开阅读时记录位置。
- 使用现有账号/演示隔离的持久草稿，同时用同账号的本机即时位置备份减少关闭前丢失。
- 删除图书或重置演示时清理对应即时位置备份；备份不会单独重建已删除图书。
- 页数变化、负数、超范围及损坏记录安全处理；视频读取中/失败的占位画面不覆盖旧视频记录。

## 保存与使用边界

账号草稿的现有同步通道会包含阅读位置，本机即时位置备份只属于当前浏览器和账号范围。测试验证了模拟账号接口的新设备往返，不等于已完成两台真实设备验收。同步失败以页面原有草稿保存状态为准，出现失败提示请不要立即关闭。清理浏览器数据会移除本机记录；未成功同步的记录无法承诺恢复。

## 手工验收建议

1. 启动上述当前代码版本，打开一本可读书，翻到第2页，回首页。
2. 确认首页「上次读到这里」及书卡显示第2页，点击「继续阅读」应回到第2页。
3. 刷新或关闭再打开同一浏览器，确认页码仍保留。
4. 点击「从头阅读」应回第一页；有视频时为0秒，且不自动播放。
5. 有视频时播放超过36秒，暂停并回首页；再次进入应恢复暂停秒数。测试时使用已有视频即可，无需重新付费生成。
6. 切换书籍/账号/演示模式，确认进度不串位。
