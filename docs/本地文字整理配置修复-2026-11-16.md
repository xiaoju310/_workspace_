# 图书分析配置缺失：本地文字整理修复

日期：2026-11-16。仅调整电脑版，未修改手机版、生产图书和账号；未调用付费模型。

## 原因

`PROVIDER_NOT_CONFIGURED` 是图书分析入口未选择分析方式，不是前端缺少豆包 API Key。
旧入口仅支持 `b_local`，要求 PaddleOCR、SmolVLM 以及视觉模型路径，不能只填一个环境变量就视为修好。

## 本次落地

- 新增 `AI_PROVIDER=text_local`：优先读取后端保存的人工校对文字，未校对的页调用本机 RapidOCR。
- 逐页保留文字与页码来源，生成最多 300 字的原文摘录笔记草稿。
- 人物、事件保持空列表，不凭规则或模型假装理解插画。元数据明确标记 `text_only`、`low_confidence`、`semantic_analysis=false`、`media=not_generated`。
- 无文字或 OCR 不可用会明确失败，不允许空笔记冒充成功。
- 笔记默认 DRAFT、保持私密，主人审核后才可分享。
- 电脑版启动脚本在未指定其他方式时启用 `text_local`；保留用户显式配置的其他 provider。
- 新前端读取服务端模式，显示“本地文字整理模式”及未执行语义分析、未生成媒体的提示；模式会跟随本书保留。

## 不包含

本次并未接通图文语义分析、自动书评、插画、视频或配音生成。`SUCCEEDED` 只表示所选文字整理任务执行成功，语义能力依旧为受限状态。纯插画无可用文字时不能完成文字整理。
后续若要人物、情节等语义能力，应另行实现并验收真正的分析 provider，不能把这条轻量路线当作比赛图文/视频功能已完成。

## 使用方法

1. 刷新电脑版当前页面，必要时 Ctrl+F5。
2. 当前失败页点击“重试本次生成”；这会按现有前端流程创建新的分析任务并同步校对文字，不修改旧失败记录。
3. 看到“本地文字整理模式”后复核内容，可进入笔记草稿。
4. 若提示某页没有文字，返回书页校对补充并保存后重试。
5. 不必在页面填写豆包密钥；启动脚本会配置文字整理方式。
