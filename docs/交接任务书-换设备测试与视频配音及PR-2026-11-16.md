## 五、任务二：为视频加入真正可保存的配音

### 5.1 最小交付流程

```text
选择已审核的分镜/讲述稿
→ 展示旁白文字、来源页码、音色/语速供主人核对
→ 主人确认（收费方案另确认费用）
→ 后端生成分段音频并持久化
→ 测量音频和视频的实际时长
→ 按页合成有声 MP4，更新真实页码时间轴
→ 网页可试听/播放，下载后也有声音
→ 换设备可重新读取同一账号的音频/成片
```

旁白默认来自主人确认的分镜讲述文本；没有合格文本时引导补充/审核，不擅自编造剧情。主人修改文本、源页、分镜或音色后，应使旧配音/审核标识失效，不能把旧音轨假称为最新结果。

### 5.2 技术方案与选择原则

- **前端：**沿用 React + TypeScript，添加“旁白稿 / 试听 / 生成配音 / 带配音视频 / 失败重试”状态和入口，复用现有样式，不重做界面。
- **后端：**沿用 FastAPI，新增可替换的 TTS 服务适配层，负责鉴权、输入校验、任务状态、缓存与音频文件存储。
- **音频：**生成真正的 WAV/MP3 等可解码文件；保存实际时长、文本指纹、音色、语速、提供方/版本和来源页码。
- **视频：**复用 FFmpeg 的工具发现与错误处理；在静音片段归一化之后做旁白合成，或重新设计明确保留新旁白的管线；成片建议兼容已有 MP4 播放链路并含 AAC 音轨。
- **存储：**元数据仍在服务器 SQLite，音频/视频文件保存在服务器受控数据目录；不另建一套前端直连云服务或数据库。

TTS 选择按以下顺序评估，不在此文档里假定任何云服务当前免费或与视频 Key 通用：

1. 先检查服务器现有可用的中文语音、资源和许可。可验证 Windows 系统中文 TTS 导出音频作为低成本备选；不能承诺每台 Windows 都有合适音色，也不能依赖交互式桌面弹窗。
2. 负责人更看重自然度时，可选正式云 TTS。先查所选提供方当时的官方接口文档，确认开通方式、鉴权、音色权限、价格和数据使用范围。豆包视频已开通不代表语音接口也已开通；密钥/接入点/应用标识等以官方要求为准。
3. 若采用开源本地 TTS，先查许可证、CPU/内存、中文质量和依赖体积；本机内存紧张，未经确认不要下载大模型或安装 GPU 环境。
4. 不把非官方免费代理、未验证的抓取接口作为唯一生产实现；不要把浏览器 `speechSynthesis` 伪装成能导出 MP3 的后端。

用一个适配接口隔离提供方；测试使用假提供方和短音频夹具。真正效果验收至少要有一次实际 TTS 输出试听；若负责人未批准付费且本地方案不可用，应明确保留该项卡点，不造假音频。

### 5.3 必须处理的音画时间关系

| 情况 | 应有行为 |
|---|---|
| 音频短于镜头 | 补静音或保留剩余画面；不要截掉后面的镜头 |
| 音频长于镜头 | 默认完整保留旁白，可延长该页末帧；设置合理时长上限并提示，过长则要求改稿/明确调整语速 |
| 跨页旁白 | 分段与对应页绑定，更新每段实际起止时间；不要继续沿用原来每页固定 5 秒的假时间轴 |
| 原视频已有声音 | 本次默认用新旁白替换原音，保留原始素材不覆盖；不擅自叠加到听不清 |
| 合成失败 | 保留原静音视频和已成功音频，不标成成功；重试不重新收费生成已有可用段 |
| 页面切换/暂停/拖动 | 以成片内音轨同步为主；试听音频必须停下，不能与视频和答案朗读叠着响 |

不得只用 `-shortest` 裁切后就宣称完成：必须实测尾句没有被截断，画面/音频总时长和页码跳转一致。

### 5.4 任务、权限、费用与重复提交

- 新接口必须使用现有账号认证/图书主人权限；服务端取已保存的原始视频，不接受客户端任意 URL、磁盘路径或 shell 参数。
- 文本长度、段数、音色参数、音频大小和任务并发要有限制；子进程超时/失败有明确反馈；Windows 后台处理不弹多个窗口。
- 用“源版本 + 文本/音色/语速指纹”标记任务，重复点击/刷新/中断恢复不会反复创建相同收费任务。
- 网络超时而提供方可能已受理时，不盲目自动重试收费；保存状态，提示核对后恢复。
- 音视频 URL 不使用旧设备临时 blob 地址作为唯一存储；鉴权下载链路须兼容网页播放与拖动。
- 缺少 TTS 配置时展示真实原因；原静音视频、原笔记仍可使用；不向前端返回密钥。
- 音色、工具、模型和测试素材来源补充到来源清单；不做未经授权的真人声音克隆。

### 5.5 建议新增的代码位置（只是建议，不是已有接口）

- `backend/app/services/tts.py`：提供方适配、参数校验、音频结果验证。
- `backend/app/narration_routes.py`：旁白稿、生成任务、状态、试听/成片接口，必须鉴权。
