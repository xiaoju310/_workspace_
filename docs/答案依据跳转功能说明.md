# 答案依据跳转功能说明

## 使用方式

1. 在互动伴读页提问，回答下方会显示「回答依据与证据」。
2. 点击某条「依据 N · 第 X 页」，在当前阅读页展开对应原书页、引用文字及本页校对文字，不跳去校对页，也不会清空回答。
3. 引用文字能在本页校对文字中逐字找到时高亮；找不到时明确提示，不把讲解或画面引用伪装成原文匹配。
4. 视频画面/讲解依据附有有效时间点时，视频载入完成后点击引用会暂停并定位。原文依据默认先展示书页，有该页可靠时间轴时，可点「定位依据视频」。
5. 点击「返回刚才位置」回到首次打开依据前的位置，保持暂停。连续切换多条依据不会覆盖返回位置。

## 边界与保护

- 服务端页码可能不连续，按真实页码查找，不直接用“页码减一”定位。
- 没有可靠视频时间点时只查看原书页，不按视频总时长均分来冒充答案依据。
- 视频元数据未就绪、播放失败或依据时间超出当前视频时长时，不错误定位；已知时长后会重新判断。
- 书页不属于当前图书时提示无法跳转，不跳到第一张或最后一张来掩盖问题。
- 没有来源时不生成虚假依据。引用和书页文字均以普通文本呈现，不执行其中的 HTML。
- 原书页预览只使用书页图片，不使用生成插画替代。引用的完整文字可查看，书页图片缺失时仍可核对校对文字。
- 仍沿用上次阅读的保存机制：保留返回位置不等于锁定持久化进度，当前停留位置仍会正常保存。

## 本轮验证

- 新增 15 项定位/文字处理测试、8 项真实阅读组件事件回归，覆盖页码映射、非法来源、时间 0、非有限时间、越界、静态跳页、高亮、视频暂停定位、返回位置、元数据晚到、资源失败及运行隔离。
- 前端完整回归：345 项通过、2 项 HTTP 测试按现有设置跳过；类型检查及正式构建通过。
- 组件测试直接执行 JSX 事件及生命周期，不等同于真实浏览器端到端测试。本轮未验证真实浏览器滚动/焦点、视频解码及手机布局。
- 本轮仅修改 C 盘当前代码工作区，未覆盖 D 盘副本、未重启现用服务、未调用付费模型、未正式发版。

## 手动验收建议

重启当前代码版本，分别用静态书页和可播放视频提问；点击多条依据，核对原文、高亮和视频时间，再点击「返回刚才位置」。同时检查没有时间轴、无引文和视频加载失败时提示是否清楚。
