# 电脑版视频生成接入与验收

更新日期：2026-11-16。范围：电脑版 `frontend-wonderland` 和共用后台，未修改 `mobile-tablet`。

## 这次补齐了什么

原来的“文字分析完成”不代表生成过视频：运行中没有视频任务、也没有 MP4 产物，阅读页只能显示书页。现在增加了独立的视频步骤：

1. 完成书页导入、文字校对和分析。
2. 在“生成进度”或“互动伴读”页找到 **让书页动起来**。
3. 点击“生成单页视频”，选择一页书页，填写希望发生的动作。
4. 阅读第三方处理及费用提醒，勾选授权，再点击“确认并生成”。
5. 后台向豆包提交任务，记录进度，将生成的视频下载到本机服务器，并登记视频来源。
6. 成功后阅读页重新读取视频和时间轴，使用带权限校验的内容接口加载视频。

**当前版本是一页、一段 5 秒、720p 的图生视频，不是全书长视频，不额外生成插画，不提供配音。** 动画是否忠实、美观仍需主人实测复核，提示词不能保证模型输出。

## 配置与费用

后台优先使用 `ARK_API_KEY`、`DOUBAO_VIDEO_MODEL` 环境变量。

Windows 下若环境变量未设置，则读取当前 Windows 用户先前保存的本机配置：

- `%LOCALAPPDATA%\PaperCompanion\Doubao\ark-key.dpapi`：当前用户加密的密钥。
- `%LOCALAPPDATA%\PaperCompanion\Doubao\models.json`：其中的 `video_model`。

密钥只在后台内存解密使用，不返回网页，不写入仓库，不在日志输出。换电脑、换 Windows 用户或改成系统服务运行时，这份加密文件可能无法解密，需要为运行服务的用户重新配置。不要把密钥填入网页“登录令牌”框；那是本项目的登录凭据。

启动和刷新页面不会自动生成。只有确认弹窗提交才可能产生新费用；金额、模型权限和账户余额以方舟控制台为准。配置可读不等于远程模型权限或余额已验证。

## 刷新、断网与失败

- 同一分析运行最多创建一个视频任务；双击或重复发送请求复用现有记录。
- 后台在提交前记录“开始提交”，获得任务号后立即保存。提交响应不明确时不自动再次提交，防止重复计费。
- 查询超时、下载中断且已有任务号时，可点 **继续查询原任务（不重新生成）**，只查询原任务和重新下载。
- 重启服务会将进行中的任务标记中断；有任务号的可手动恢复查询，不会自动提交新任务。
- 提交结果不明确、服务商明确失败或过期时，先到方舟控制台核对。重新分析会创建新的运行，再次确认生成可能产生新的费用。
- 视频失败不把成功的文字分析改成失败。
- 视频处理期间不允许删除本书。不同用户不能查看、提交或恢复别人的视频任务。

## 数据与接口

账户仍使用原 MongoDB；业务运行、视频任务记录沿用项目现有 SQLite，不在这次进行数据库迁移。视频文件保存在服务器 `data/runs/<run_id>/video-<job_id>.mp4`，通过项目已有的受保护内容接口读取。

新增接口（均需本人登录）：

- `GET /api/runs/{run_id}/video`：读状态。
- `POST /api/runs/{run_id}/video`：明确确认后创建，参数 `page_no`、`prompt`、`duration: 5`、`confirm_paid: true`。
- `POST /api/runs/{run_id}/video/resume`：只恢复查询，不新建服务商任务。

付费生成不使用普通文字分析任务的通用重试接口。来源图上传前校验受控路径及内容哈希；视频下载限制为服务商 HTTPS 域名，并限制大小，不携带模型密钥下载媒体。
