# 电脑版换设备登录与账号同步

日期：2026-11-16  
范围：电脑版；不修改手机版；本次未提交或推送代码。

## 1. 这次解决什么

以前“能登录同一个账号”不等于“能看到同一本书”：账号在服务器，书架和导入草稿主要在原来的浏览器中。现在登录真实接口模式后，会把账号自己的书架快照和书页原图保存到同一台服务器，并在其他设备登录时恢复。

| 内容 | 现在的行为 |
|---|---|
| 书架、图书分类与校对内容 | 随账号保存和恢复 |
| 书页原图 | 先上传原图，再保存引用；不会把只能在旧浏览器使用的临时图片地址当作已同步 |
| 未完成的导入草稿 | 同步书名、页序、原图等，可在另一设备继续导入 |
| 私人笔记、分享记录、互动记录 | 保存在账号书架快照中；不会因同步自动公开或自动通过审核 |
| 阅读位置 | 恢复书页位置；视频可用时恢复播放位置，不保证逐帧同步 |
| 以前已经导入服务器的书 | 尝试从服务器原书和原图恢复；不会擅自跳过内容审核 |
| 多设备同时修改 | 检查版本；旧设备不能直接覆盖另一设备的新版本 |
| 不同账号 | 服务器按登录账号隔离草稿与原图；不能只凭图书编号读取别人的内容 |

**不是实时多人协作，也不是把数据上传到独立云存储。** 原电脑仍然是服务器。新设备应连接同一个服务器、登录同一个软件账号。

## 2. 第一次使用：先在原设备同步一次

1. 保持服务器电脑开机，先在原来保存了图书的浏览器中打开电脑版并刷新页面。
2. 登录原来的软件账号，使用真实接口模式。不要先清理浏览器数据。
3. 在书架上点击 **“保存书架草稿”**，等待显示 **“已同步到账号（可换设备）”**。有多本书时，首次上传原图需要一些时间。
4. 如有尚未完成的导入，进入该导入草稿，点击 **“保存草稿”**，同样等待“已同步到账号”。
5. 然后在另一台电脑打开同一服务器的软件地址，登录同一个软件账号；书架和可继续的导入草稿会加载出来。
6. 切换设备前再次确认已同步。离线、同步失败或还在保存时，不要直接关闭页面或清除浏览器数据。

旧浏览器里的数据不会在它尚未打开新版时凭空传到服务器。若原电脑、原浏览器已经丢失且此前从未同步，仅靠账号无法恢复那部分本地草稿。

### 校园网或异地访问

继续使用项目已有的 **Tailscale 私有共享启动入口**，把启动后显示的软件 HTTPS 地址发给获准访问的设备；新设备需连到获准使用的同一私有网络。Tailscale 登录与本软件账号登录是两回事。新设备不用安装 MongoDB，也不用单独启动一份后端。

不要在另一台电脑输入 `127.0.0.1:8000`：那指的是另一台电脑自己，而不是这台服务器。不要开放 MongoDB 端口或使用公网端口映射来解决登录问题。原电脑关机、休眠或共享网络断开后，新设备无法访问服务器。

## 3. 两台设备修改冲突怎么办

出现 **“其他设备已经更新”** 时，表示服务器保护了较新的版本；旧设备的修改仍尽量保存在本机，没有静默覆盖。

1. 暂停在多个设备同时编辑，确认要以哪一份为准。
2. 在旧设备点击 **“备份本机并重新同步”**。它会先触发下载 JSON 备份，然后清除当前账号的本机草稿记录并刷新，重新读取服务器版本。
3. 检查浏览器确实下载了备份；备份可能包含原图、私人笔记和图书内容，请妥善保管，不要上传公开仓库。
4. 若要保留旧设备特有的修改，根据备份人工补回。**当前没有一键导入备份、自动合并两份冲突或实时协同编辑功能。**

## 4. 数据实际上保存在哪里

- MongoDB：账号、登录会话等认证数据，沿用原配置。
- 服务器 SQLite：图书/任务/笔记等业务记录，以及新增的账号草稿快照、同步原图。
- 服务器文件目录：已有图书原图、生成产物等仍保留原存储方式。
- 浏览器：保留本机草稿缓存和未成功同步的修改，作为断网保护；不能代替服务器备份。

备份时应一起备份服务器 SQLite、相关图书/生成文件，以及 MongoDB 的账号数据；不要只复制 MongoDB 就认为图书也备份了。服务器数据也不是自动异地灾备。

当前同步原图只接受可完整解码的 JPG/PNG，每张最多 20 MB、4000 万像素；单份草稿请求最多 8 MB 元数据。服务器会按账号去重原图，但暂未实现总容量配额、未引用原图自动清理。删除图书不承诺立即物理擦除所有历史同步图片；需要控制磁盘空间并保护服务器备份。

## 6. 主要代码入口

- `backend/app/library_routes.py`：账号草稿、原图、版本保护、历史图书恢复接口。
- `backend/app/db.py`：新增账号草稿和原图表，不删除旧数据。
- `frontend-wonderland/src/lib/accountDrafts.ts`：原图同步、临时地址恢复、账号切换保护。
- `frontend-wonderland/src/features/books/draftStore.ts`：本机缓存与服务器版本衔接、冲突和备份。
- `frontend-wonderland/src/app/WorkspaceApp.tsx`：登录恢复、保存状态、重新同步入口。
- `frontend-wonderland/src/pages/ImportBookPage.tsx`：未完成导入的账号保存。
- `frontend-wonderland/src/pages/InteractiveReaderPage.tsx`：阅读位置保存和恢复。
- `backend/tests/test_library_sync.py`、`frontend-wonderland/src/features/books/__tests__/accountSync.test.ts`：新增自动测试。
- `frontend-wonderland/scripts/check-account-sync.cjs`：独立浏览器 + 隔离数据库验收；只应用于测试服务器，不要对真实账号运行。
