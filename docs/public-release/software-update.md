## 已知边界

本机模型仍可能误答，尤其是跨页比较、隐含动机和代词；不能替代人工核对。
普通问答与点选识物的本机开关不覆盖全部云端功能。
在线配音、云端视觉和视频生成仍需独立授权与配置，可能联网或收费。
旧后台不会因浏览器刷新自动更新；更新代码后需重新启动软件后台。
自动化测试不等于浏览器、麦克风、播放器及整本书的端到端验收。
