# PDF 导入专项验收

日期：2026年11月22日。范围：代码修复、隔离数据测试和前端构建；不包含真实模型生成及现场交互验收。

## 已修复
- 正常 PDF 被误报损坏：解析页面改为显式生命周期管理，关闭页面、位图与图片。
- 部分页遗留：一份 PDF 只有所有页面格式、页序和图片校验通过才加入；失败释放这份文件的临时图片。
- 账号及页面切换：取消旧请求、丢弃迟到结果、清理图片链接，防止旧导入结果在新账号出现。
- 重复选择：检查中的批次拒绝重复进入；后续请求使用实际剩余页数。
- 文案明确 PDF 发送到当前服务器本地解析，不调用云端模型，不将服务器位置等同于用户电脑。

## 验证证据
| 项目 | 方式与结果 |
|---|---|
| 正常PDF | Pillow生成真实三页彩色PDF；实际PDFium解析、Pillow解码输出JPEG；逐页颜色、顺序、尺寸匹配 |
| 密码PDF | 自制AES-256加密样本可用测试密码打开；未提供密码时422拒绝；随后正常PDF仍可处理 |
| 损坏与限额 | 空/非PDF/损坏、输入大小、页数范围、剩余页数、输出大小、繁忙、缺组件均覆盖 |
| 本机草稿 | 前端真实DraftStore与隔离IndexedDB保存、重新实例化恢复；各页字节、文件类型、页序和账号隔离通过 |
| 后续交接 | 导入页确认后交付有序JPEG File及授权信息至校对回调，不重新解析PDF |
| 后端原图 | 测试书中逐页上传解析所得JPEG，读取字节相同；其他账号不可读取 |
| 迟到结果 | 换令牌/账号作用域、卸载、清空后不加入旧页；全部临时图片释放 |

前端PDF专项20项；前端全量473通过、2项需在线环境的用例跳过。生产构建通过。后端相关六个文件73通过、3条依赖弃用提示。输出见前端pdf-wrapup-tests.txt、pdf-wrapup-build.txt和后端pdf-wrapup-tests.txt。

## 限制与待验收
- 前端测试的Image.decode使用替身，持久化使用fake-indexeddb；这些证明数据和生命周期逻辑，不证明真实浏览器显示效果。
- 输入PDF上限30 MB、单书100页；超过剩余页数不截断成半本。展开JPEG总计64 MB、最长边2000像素；JPEG转换不等同于无损保存PDF原始矢量。
- 解析预览不保留PDF源文件；用户继续保存草稿时才保存/同步转换所得图片。
- 不提供解密输入框，密码PDF需先由有权用户自行解密再上传。
- 真实浏览器新PDF→OCR校对→生成→播放→交互尚未全流程验收；OCR准确率、真实生成质量及语音实际首音不能从本次测试推出。
- 运行时依赖沿用后端已有pypdfium2/Pillow；未为运行程序增加PyMuPDF依赖。加密样本仅为测试材料，不含真实书或用户内容。
- 未调用收费模型、未操作正式书库、未提交或推送代码。
