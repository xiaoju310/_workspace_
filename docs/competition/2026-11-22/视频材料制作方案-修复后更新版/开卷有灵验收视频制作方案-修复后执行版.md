## 3 整书非交互视频制作流程

### 先准备并核对原书

- [ ] 分别建立中文、英文目录。负责人确认授权PDF、真实页序、正文范围及重要无字页；英文01未定案前不生成正式英文提交件。

- [ ] 导入新PDF，完成文字和分镜校对。逐页填写随附覆盖表，列出人物、事件、场景、关键原画面文字，不以OCR成功代表理解完整。

### 由软件生成并保留来源

- [ ] 按界面提示逐项确认模型费用和批次。长书同一运行按批处理，每批最多12页且独立授权；失败批次不盲目重试，不自行购买额度。

- [ ] 保留原输入指纹、运行ID、实际模型ID、任务日志、每个原片段、登记成片和可靠时间轴。时间轴必须对应实际生成资产，不按总时长除以页数猜位置。

当前流程为逐页生成片段后系统自动合成整书。FAQ43“一次生成，不能二次编辑”同时涉及生成视频和交互视频，内部合成边界仍待确认。不要额外用剪辑软件拼补、配替代旁白、加字幕补文字或改速。

### 完整看完并逐页验收

- [ ] FAQ33要求正文每页有所体现；可跨页连续镜头，不要求一页一镜。逐页对照实际成片的人物、事件、场景和重要无字情节，不只检查页码映射。

- [ ] 核对英文旁白语言、叙事顺序、有意义动态、画面与声音。停帧、重复片段和漂亮片段集锦不能代替完整绘本。

- [ ] 依现有本地清单先按100至180秒、至少720p和24fps准备；这是待负责人核对的保守制作目标，不用重编码或补帧凑指标。实测最终文件时长、尺寸和帧率。

未通过的原始生成文件完整保存，记录漏页、错场景、无字页遗漏等问题。能否另起完整运行重做由主办方口径决定，不自行挑选多次运行的成功片段。

## 4 交互录屏前的准备

### 负责人交接

- [ ] 交付完整可运行软件或访问地址、专用演示账号、受限素材的安全取用方式、当前版本及技术联系人。不得只发启动文件，也不得在群里发密钥。

- [ ] 交付已登记整书视频、书与运行ID、视频指纹、已校对原文和分镜、可靠时间轴、逐页覆盖核对结果。仅有视频文件不足以保证场景口令可用。

### 设备与声音

默认使用电脑版，不临时换平板。接好电源，关闭休眠、通知和无关窗口；录屏须同时覆盖播放区、伴读助手、识别文字、回答及必要状态。建议直接录为MP4、1080p、30帧和可见鼠标，这些是制作建议，不是新增官方硬指标。

- [ ] 先录约20秒设备试片并回放，确认软件麦克风实际收到官方音频，同时录屏能听到原指令和系统回答。耳机可听不等于麦克风收到，不临时更改未经验证的音频路由。

### 进入软件并独立授权

- [ ] 使用交付的软件启动方式，登录专用演示账号；确认“真实后端 · Live”，不能用Demo模拟回答。加载已登记真实成片，等待播放就绪。

- [ ] 确认提问语言和“识别定稿后自动提问并朗读答案”。英文音频的实际浏览器识别路线先排练；语言切换发生在正式录屏内时不能剪掉。

- [ ] 分别确认“语音文字框选收费授权”“语音看图问答收费授权”；点击识物也须按自身提示开启并独立授权。授权不等于免费，不授权时提示或拒绝不能算功能成功。

书级语音授权绑定当前书、运行、视频与登录身份。同书换页可保留，换书、换视频或重新登录后重新授权并发送新口令；不能指望旧口令在勾选后自动执行。不得自动重试收费请求。

正式开录前清理测试回答和无关信息，保留必要版本信息。试录和排练单独标记，不能混进正式连续原片。

## 7 正式录屏的连续执行

### 从开录到结束

- [ ] 按已确认起点开始录屏；若允许从已生成阅读页开始，简短展示书名、真实模式与成片。若要求包括PDF输入和生成，须按该口径另作完整记录，不伪装现场一次生成。

- [ ] 每条音频：打开真实录音入口，播放该编号原文件，待原音频完全结束后结束录音，等待最终识别、实际动作和回答。开始录音不应暂停视频；部分识别、报错或人工改字需如实记录。

- [ ] 01使视频播放，开录02期间应继续播放，直到识别到暂停口令才停止。03从原暂停处继续。50应停止并归零，不用关窗口代替。

- [ ] 场景指令只依可靠文字或分镜与时间轴匹配片段起点。缺依据、多个候选、时间轴缺失或越界时记录失败，不靠手拖时间条掩盖。

- [ ] 需要点击时，目标出现且视频仍在播放，点击后观察暂停、目标框和信息。仅有点击圆圈不等于识物成功。若已暂停，先明确恢复播放并记录辅助操作，不冒充必选口令成功。

- [ ] 语音看图或框字时等待当前真实帧结果；播放或跳转后旧结果应取消。不要同时发多个指令，也不把先前帧的回答当成本帧成功。

- [ ] 执行50后保留最终状态再停录。录屏中不暂停、不切段，不剪掉失败、等待或卡顿，不补录拼接，不添加或替换系统回答。

### 不混算成绩

手动输入看图或文字查找可用于排查，但不算官方语音链路通过。框字仅当前帧，不等于全片检索；当前帧问答不等于整段视频时序理解。原因问题无对应人物动作的明确原文应拒答，不把拒答自动记为任务成功。

正式录屏里出现的必要授权、语言切换、恢复播放均保留并记录。不能把辅助按钮动作计入13条原音频的成功数。

## 8 排练节奏与失败处理

|排练时间|建议安排|
|---|---|

|0:15至0:45|依次完成01至03播放控制。|
|0:45至1:55|第一组场景定位、播放中点击、画面问题和框字。|
|1:55至4:30|依原编号完成其余必选定位、点击和跨语言项目。|
|4:30至5:00以内|完成结束播放，停录前保留结果。|

这是排练预算，不是实测耗时保证。交互原片按现有材料控制在5分钟以内；若完整原音频和真实等待导致超时，提前报负责人，不删必选项、不加速、不截断原音频或剪等待。

|现场问题|处理方式|
|---|---|
|识别错或未定稿|保存原识别，记首次失败或未完成；人工改字和重试另记，不能改写首次结果。|
|错场景或目标不出现|记目标及实际时间；片段起点不等于目标动作。不能手拖补成成功。|
|错框或没有文字|保留真实帧、框和提示；不后期加框或字幕。|
|服务报错或长时间等待|保留报错和等待；无法继续则保存整条为未完成，不接另一条成功片段。|
|隐私出镜或超时|原片只留本地安全保存，联系负责人；不把泄露版公开，不以后期模糊或裁切当正式原片。|

准备阶段允许设备试录和内部排练。正式失败后是否允许另起完整运行或重新录制，应取得主办方口径；保留旧失败原片，不自行挑一条当作已符合“一次生成”。新运行另编号，不覆盖旧文件。

## 9 证据记录与原始性核验

### 逐项记录

随附CSV已列中文15项和英文01候选15项，全部为待执行。原音频文件名仅14号有已核实异常命名，其余从实际官方目录照抄，不自行猜文件名。录制者逐行填写真实结果，不能预填通过。

- [ ] 记录软件完整提交号、书与运行ID、视频ID和SHA256、原编号及音频原文件名、录屏起止时间、识别原文、实际动作或回答、失败原因和人工判断。

- [ ] 定位项填写目标画面时间与实际视频时间；点击填写点击前是否播放中及点击后的框和暂停状态。语音框字和看图记录对应真实帧和授权状态。

- [ ] 需要播报的项目，从原音频语音结束计到录屏声轨实际可听回答首音，记录延迟和是否两秒内。无声或失败也保留分母；不适用播报的控制项注明不适用，不填0秒。

界面“浏览器播放启动≤2秒”和接口耗时不能代替耳朵实际听到首音。软件统计JSON可作辅助证据，不能取代原始录屏和人工复核。

### 原始文件与来源

- [ ] 录屏软件直接输出最终录制格式，原片不改速、不裁切、不拼接、不二次配音或压缩。若只有其他原生格式，先保留并请负责人确认转换规则，不自行转换当原始MP4。
