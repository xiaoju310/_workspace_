## 3. 每次回归要记录的耗时

| 字段 | 现状 |
|---|---|
| `latency_ms`（发起问答/触控 → 拿到结果） | 已记录并写入后端留痕；非流式，文字一次返回，所以这个值也就是"首字"时间 |
| TTS 首音（点击朗读 → 第一声） | 阅读页实时显示；**未写入后端留痕**（A 的交互接口只接受 voice/touch 且只能追加），导出文件里没有这一项 |
| ASR 耗时 | 浏览器语音识别不提供分段耗时；接入 A 的服务端 ASR 后再记录 |

导出：历史页「导出后端留痕与延迟统计」→ CSV + 统计 JSON（P50/P95，缓存命中与未命中分开）。
