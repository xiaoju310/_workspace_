## 3. 抽取式算法能力缺口清单与迭代方向

1. **时序意图理解缺口（2项，GS-09, GS-10）**：
   - 现象：孩子常问“开头”、“结局”、“后来怎么样了”，原书文字通常并不包含“开头”、“结局”字样。纯字符二元组字面匹配对此完全无能为力。
   - 依赖项：需要角色 B 的文本模型或时序意图语义向量嵌入（Dense Retrieval）。
2. **跨语言/同义词对齐缺口（1项，GS-11）**：
   - 现象：“red scarf”无法匹配中文“红围巾”。
   - 依赖项：需要多语言 Embedding 或跨语言词表映射。
3. **单字与短查询防噪与召回的权衡（1项，GS-12）**：
   - 现象：“鸟”作为单字被过滤，防止“了”、“的”等单字引起全库爆炸，但也导致了单字实体的漏召回。
4. **长问句关键词稀释（1项，GS-13）**：
   - 现象：问句过长导致 `matched_bigrams / total_bigrams < 0.4`。
   - 现状：已通过独立的儿童安全规则守住底线，无论是否满足覆盖率，一律附加安全警告。

### 4.2 单字符与独立数字的丢失
- 当前分词为了防止“的一是不了”等单字噪声，设置了 `if (run.length === 1) continue;`。
- 后果：儿童常问的单个字（如“鸟”、“花”、“狗”、“1”）由于长度为 1，直接被丢弃，导致二元组为空，100% 拒答。

### 4.3 跨语言与同义词
- 纯二元组基于字面完全匹配，英文无法匹配中文概念，同义词（如“大鸟” vs 原文“大雁”）无法对齐。这必须依赖真实 Embedding 或 LLM/VLM 模型。

## 5. 改进方向与演进路线
1. **短期规则优化**：
   - 当检测到时序意图（`wantsBeginning` / `wantsEnding`）时，若无其他实体冲突，可直接赋予保底有效性；
   - 对单汉字，可引入高频儿童名词白名单（动物、植物等），或者在无其他二元组时允许单字匹配；
2. **长期模型接入**：
   - 接入真实后端模型服务（B/A 端视觉与文本大模型），将二元组作为离线降级方案，彻底解决语义对齐与同义词理解。
