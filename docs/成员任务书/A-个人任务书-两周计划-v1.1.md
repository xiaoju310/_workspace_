## 2.1 技术栈与工具（执行版）

### 必须使用

- **后端语言**：Python 3.x。
- **Web 框架**：FastAPI + Uvicorn。
- **数据校验**：Pydantic；接口契约以 OpenAPI `/docs` 为准。
- **开发期数据库**：SQLite；连接开启外键检查和 WAL。
- **测试**：pytest + FastAPI TestClient/httpx。
- **任务编排**：Python 后台任务和数据库状态机；两周内不新增 Redis、Celery 等复杂基础设施。
- **文件处理**：Python `hashlib` 计算 SHA-256；FFmpeg 由 A 统一管理音视频命令。
- **协作工具**：Git + GitHub Desktop；分支 `team/a-backend`，只能通过 Pull Request 合并到 `main`。

- 目录：`backend/app/main.py`、`backend/app/db.py`、`backend/app/api/`、`backend/app/services/`、`backend/tests/`、`docs/api-contract.md`。

3. 每天 17:30 跑测试，18:00 提交代码和自测结果，20:00 配合集成。
