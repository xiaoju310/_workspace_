## 2.1 技术栈与工具（执行版）

### 必须使用

- **后端接口测试**：pytest + httpx/FastAPI TestClient。
- **前端验收**：Chrome/Edge 手工用例；条件允许时使用 Playwright 做关键路径回归。
- **数据记录**：CSV 记录用例、输入、预期、实际、状态、耗时和证据；Markdown 汇总结论。
- **指标计算**：Python `statistics` 或简单脚本计算成功率、准确率、P50/P95，并写清公式。
- **安全检查**：参数越权、分享过期/撤销、原文泄露、日志密钥泄露、路径穿越、多书串数据。
- **协作工具**：Git 分支 `team/e-testing-docs`，通过 Pull Request 合并；不提交授权书页、真实儿童数据、密钥和模型权重。
