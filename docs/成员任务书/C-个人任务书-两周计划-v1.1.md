## 2.1 技术栈与工具（执行版）

### 必须使用

- **前端语言**：TypeScript。

- **测试**：浏览器手工测试 + TypeScript 类型检查 + 10 条固定问答样例。
- **协作工具**：Git 分支 `team/c-interaction`，所有改动通过 Pull Request 合并。

1. 先做录音开始/停止/转写显示，再接真实 ASR。

3. 每天用 10 条问题和 5 次点击回归，记录首字、首音频时间和失败原因。
4. D 负责布局，C 负责录音、坐标、请求和状态逻辑。
5. 提交格式：`feat(interaction): ...`、`test(interaction): ...` 或 `fix(interaction): ...`。
