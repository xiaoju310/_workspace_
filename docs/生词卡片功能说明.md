# 生词卡片功能说明

## 使用方式

1. 在互动伴读页向下找到「生词卡片」，点击「添加生词」。
2. 填写生词、释义和例句。生词必填，释义及例句可留空以后补充。
3. 检查来源书页。静态页或可靠视频时间轴会带入当前真实页码；正在查看答案依据时优先带入该依据页。视频还未载入、出错或只有估算页码时，不自动猜来源页，可手动选择或不关联书页。
4. 保存后点击「翻卡看释义」复习，使用「标记已掌握」「还需复习」调整状态。支持「全部」「待复习」「已掌握」筛选。
5. 点击「回到原文」复用答案依据预览；可核对书页，并通过「返回刚才位置」继续阅读。
6. 可修改卡片，删除前需要再次确认。

## 保存与边界

- 卡片按图书保存，随现有书架草稿存入本机。登录账号且现有同步成功时，随账号草稿同步；不另建公共词库或外发查询。
- 页面上方的草稿状态是保存/同步是否成功的依据。保存失败不要立即关闭页面，按已有提示重试。生词卡没有另行承诺离线跨设备自动合并。
- 删除图书或重置演示书架时，所属生词随图书一并移除；不同账号、演示和正式模式沿用已有草稿隔离。
- 旧书无此字段时显示空词卡，不修改原有阅读进度、笔记或答案。
- 同书同词做空白、全半角、大小写归一化后避免重复；不同书可以各自保存相同词。
- 生词最多80个字，释义和例句各1000个字；所有内容按普通文字显示，不执行其中的HTML。
- 释义和例句由用户填写、核对，本版不接在线词典，不自动生成释义或调用收费模型。来源页是阅读定位线索，不代表释义已被模型或词典验证。
- 本版为逐卡翻看和手动掌握状态，没有间隔复习排程、自动拼音或发音能力。

## 本轮测试

- 新增20项回归：5项数据逻辑、10项卡片组件事件、3项阅读页接入、1项本机持久化与账号隔离/删书清理、1项模拟账号同步恢复。
- 完整前端回归365项通过、2项HTTP联调测试按原设置跳过；类型检查及正式构建通过。
- 测试直接执行组件事件与草稿存储逻辑，模拟账号接口并不等同于真实第二台设备验收。本轮未进行真实浏览器点击、视频解码及移动端视觉验收。
- 仅修改C盘当前代码，未覆盖D盘副本，未重启现用服务或正式发版。

## 手动验收

重新启动当前代码版本，打开一本书添加两张卡；翻卡、修改、切换掌握状态及筛选，再刷新确认恢复。点来源回原文核对；取消删除后确认卡片还在，确认删除后刷新核对不再出现。
