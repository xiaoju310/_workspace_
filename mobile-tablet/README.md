# 手机／平板独立版本

这是**适合手机、平板浏览器打开的响应式网页版**，不是安装用的 Android APK 或 iOS App。代码、启动端口及业务数据库与电脑端分开；不要用电脑端 8000 的地址打开它。

## 数据放在哪里

- 服务运行在**你的电脑**上。手机、平板仅访问网页和 API，**不安装 MongoDB**。
- 默认使用本机 `mongodb://127.0.0.1:27017` 的独立数据库 `paper_companion_mobile`。账号、登录会话、书籍、分类、书页校对、分析任务、笔记、分享、交互记录和真实模式的阅读工作区都存入这个库。原书图片和登记的视频等文件放在这个库的 GridFS；临时分析文件不作为持久副本。
- 电脑端继续使用原来的 SQLite 和自己的 MongoDB 账号库；两版账号**互不相通，需在移动版另行注册**，书籍也不自动同步。桌面端文件夹和启动脚本均不改变。
- 演示模式仅是浏览器里的样例，不写 MongoDB；真实模式须登录。登录令牌仍短暂保存在浏览器会话中，不是长期保存的文件。录音原文件和触控截图没有上传接口，只保存指纹／元信息；要保存原文件请另行导出。
- 生成视频需要额外的模型、费用和产物登记；这里没有承诺点一下就能生成视频。没有配置真实分析 provider 时任务会明确失败，不伪造成功。

## 启动

1. 确认电脑上的 MongoDB 服务运行，且只监听 `127.0.0.1:27017`，不要开放 27017 到校园网／公网。
2. 双击当前目录下的 `start-mobile.cmd`。首次启动会安装本目录自己的 Python、Node 依赖；需要联网且稍等片刻。
3. 本机浏览器打开 `http://127.0.0.1:5174/`，在**真实模式**注册／登录后导入有授权的图书。移动版 API 在 `127.0.0.1:8001`。不要给其他设备使用 `127.0.0.1`，那指的是它们自己。
4. 如需手机／平板访问，在这些设备及电脑登录同一受控 Tailscale 网络，把本机 `5174` 的网页通过 **Tailscale Serve** 提供 HTTPS；确认现有 Serve 配置后再设置，不覆盖电脑端已有的 443 分享。不要启用 Funnel，也不要公开数据库端口。若设备访问不到，先检查电脑没有睡眠，Tailscale 已连接，再检查 Serve 状态和网络权限。

## 开发与验证

- `npm --prefix mobile-tablet run build`、`npm --prefix mobile-tablet test`。
- 在仓库根目录设置 `PYTHONPATH` 为 `backend` 与 `mobile-tablet` 两个绝对路径（Windows 用分号连接），使用 Python 执行 `mobile-tablet/server/smoke_mongo.py`。脚本创建**临时测试库**，结束后删除该测试库，不碰正式移动版数据。
- 后端启动失败查 `mobile-tablet/logs/api-error.log`；前端失败查 `mobile-tablet/logs/ui-error.log`。

真实设备／Tailscale 分享需在有设备登录的环境里另行验收。此版本不会把旧电脑端的 SQLite 数据迁移或复制到新库。

## 自动识别书页文字（可选）

在仓库根目录运行：

```powershell
mobile-tablet\.venv\Scripts\python.exe -m pip install -r backend\requirements-ocr.txt
```

重启对应的服务，再用已登录的真实模式导入 JPG/PNG 书页。系统会逐页识别文字，填入“文字校对”草稿；识别结果可能有错漏，必须人工检查并确认。识别失败可手动填写文字/画面描述；已经导入的未确认书页可以在“文字校对”页点击“重新识别这一页”；为保护手工修改和已确认内容，先保存/处理未保存的修改，已确认页不会被 OCR 覆盖。首次使用可能需要等待模型初始化。此组件与整书 AI 分析/视频生成配置不同；安装 OCR 不会解决 `PROVIDER_NOT_CONFIGURED`。演示模式不发送书页到 OCR 服务。


### 校对辅助提示（2026-11-16）

- 校对页使用“识别参考分 / 100”，不是准确率；所有页面都提示对照原图检查，不能因高分跳过人工确认。
- 单独成行的部分装饰符号和少量可疑拉丁字符会按行号提示（例如 `●`、`à`、`II`），只做提醒、不自动删改。短行、页码、英文仍保留；提示不覆盖所有错字或顺序问题。
- “重新识别这一页”会把本次参考分与草稿一起更新，保存后使用本次分数，不继续沿用上次识别的旧分数。
- 原创绘本的 30 项本机模拟测试说明、边界与实拍验收清单见仓库 `docs/OCR-校对改进与验收.md`。模拟变换不能代替真实拍照验收。
