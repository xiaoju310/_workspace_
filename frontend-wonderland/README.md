# 开卷有灵 · 奇想纸艺世界（视觉重构版）

「**奇想纸艺世界 / Wonderland in Paper**」——本项目的前端视觉重构版本。

> 当前电脑版唯一前端为本目录。旧 `frontend/` 已于 2026-11-17 清理，不再支持切换。
> 下面的视觉重构说明保留创建时背景；当前运行、同步和验收状态以根 README 及最新交付文档为准。

## 先看效果（无需安装、无需联网）

双击 **`preview.html`**。

这是一个把全部 TS/TSX 与 CSS 打包进单个文件的离线预览页，内置 React，打开后即为 **Demo 模式**（不需要登录、不请求后端）。左侧导航可走遍全部页面。

重新生成：

```powershell
node scripts/build-offline.cjs
```

## 作为真实前端运行

```powershell
cd frontend-wonderland
npm install          # 首次需要联网
npm run dev          # 默认 http://127.0.0.1:5173，/api 代理到 127.0.0.1:8000
```

接真实后端时先按仓库根目录 `backend/README.md` 启动 FastAPI（8000），再 `npm run dev`。

```powershell
npm run build        # tsc -b && vite build
npm run preview      # 预览生产构建
```

> 本目录现在使用自己的 `node_modules/`，不再链接旧前端。新电脑在本目录运行 `npm ci` 安装锁定依赖；`node_modules/` 不提交仓库。

## 设计语言

| 维度 | 约定 |
|---|---|
| 核心概念 | 立体纸艺拼贴 + 梦幻水彩 + 艺术杂志式排版 |
| 主色 | 深海蓝绿 `#285E63`；珊瑚橙 `#F07862`；琥珀金 `#E8BC58` |
| 辅助色 | 鸢尾紫 `#9185C8`、鼠尾草绿 `#91A98A`、陶土玫瑰 `#C77D67`、晴空蓝 `#6D91B4`、雾粉 `#D7A7B7`、暖沙棕 `#D5A17D` |
| 基础色 | 背景 `#F7F5EF`、卡片 `#FFFEFA`、次级 `#EDEFE5`、特殊 `#EAE8F2`、标题 `#263B3C`、辅助文字 `#74817B` |
| 状态色 | 成功 `#4D9674`、加载 `#6D91B4`、等待 `#D5A13F`、警告 `#E88759`、失败 `#C65D5D`、信息 `#9185C8` |
| 圆角 | 12 / 20 / 28 / 999 px |
| 间距 | 4px 倍数体系（`--s-1` … `--s-11`） |
| 阴影 | 接触阴影 + 柔和扩散 + 彩色环境光，三层以内 |
| 字体 | 展示用衬线（印刷绘本感），正文用无衬线（中文可读性优先） |

## 每个页面的空间构造

不是同一套卡片模板换皮，而是按功能设计不同的空间形式：

| 页面 | 空间构造 |
|---|---|
| 首页 | 立体纸艺主视觉：打开的绘本中长出森林与山峦，标题压在画面上；错落的推荐位；带搁板的书架 |
| 导入 | 纸艺工作台：图纸网格上传槽、粘在右侧的「安心卡」 |
| 校对 | 编辑台三栏：书脊式页序、胶带画框原图、横线纸编辑区 |
| 分类 | 标本卡 + 主人选择卡，类型选项层叠 |
| 生成 | 工作台：进度大数字、六阶段竖向轨道、收据式运行记录 |
| 互动阅读 | 沉浸式深色纸剧场：画框角标、悬浮控制条、右侧伴读纸签 |
| 历史 | 记忆长廊：三块计数石 + 竖向时间轴 |
| 笔记 | 笔记本左右页：横线纸编辑 + 审核清单 |
| 分享 | 纸飞机与凭证卡：分享方式票据、登机牌式只读链接 |
| 只读分享 | 礼物卡：大字摘要 + 引文块 |
| 设置 | 克制的立体功能面板，减少装饰、保留纸张与层次 |

## 童趣增强层（追加）

在纸艺世界之上又加了一层孩子气，实现是 `src/styles/playful.css`（最后加载，只覆盖外观、不动布局）：

- **更圆**：圆角放大到 14 / 24 / 34；按钮变厚，带「按下去会沉」的立体底边。
- **更亮**：新增儿童色卡（阳光黄 `#FFD24A`、泡泡粉 `#FF9DB4`、天空蓝 `#7FD0F5`、草地绿 `#8AD469`、葡萄紫 `#B39CF5`），只用于强调与装饰，正文对比度不变。
- **会动**：封面卡片悬停弹性抬起、品牌图标偶尔「抖耳朵」、空状态图标轻跳、涂鸦缓慢浮动，全部受 `prefers-reduced-motion` 约束。
- **有小伙伴**：`src/components/Doodles.tsx` 提供 14 个手绘涂鸦（云、太阳、彩虹、狐狸、兔子、气球、铅笔、星星…），用于首页主视觉周围与空状态。
- **手作痕迹**：卡片内圈虚线、蜡笔条纹进度条、贴纸式徽标与选中标签、便签风页脚。

想调强弱只改这一个文件；完全去掉就删掉 `src/index.css` 里的 `@import './styles/playful.css'`。

## 儿童版（Kid Mode，追加）

再往上一层：`src/styles/kidmode.css`（最后加载）+ `src/components/ReadingBuddy.tsx`。

- **大一号的触达**：按钮 56px、输入框 54px、导航项更大——小手指点得中。
- **更冲的颜色**：主色退居次要，阳光黄成为主角；每页右上角有一圈淡阳光，工作流卡片顶部有彩色标签纸（导入黄 / 校对蓝 / 分类粉 / 生成绿）。
- **会说话的小伙伴**：右下角常驻伴读小狐狸，按页面说一句孩子气的话（「故事正在长大，等一下下～」）。点它切换气泡，双击收起，收起后变成圆形小按钮。纯提示，不替代任何操作。
- **做完有奖励**：已确认的书页是金色小星星，步骤条变成大圆珠，进度条是蜡笔条纹，笔记来源编号变成黄色圆贴纸。
- **首页**：更大的狐狸 + 一只兔子坐在画框边，配一个「今天，翻开哪一本？」的气泡。

三层叠加关系：基础纸艺 → `playful.css`（童趣）→ `kidmode.css`（儿童版）。
想退回中间档，删掉 `@import './styles/kidmode.css'` 即可；想更野可以只保留 `kidmode.css`。

## 已验证 / 未验证

因此请以 `preview.html` 或 `npm run dev` 的实际渲染为准；如发现间距、断点或对比度问题，请按页面指出，我按截图逐项修。
